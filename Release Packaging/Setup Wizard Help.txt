CASUALTIES HUB SETUP WIZARD - SIMPLE HELP
===========================================

WHAT IS THIS?
-------------
This is the Setup Wizard. It installs, updates, or removes the Casualties Hub Mod Manager.

The Setup Wizard does NOT install mods by itself. It gets the Casualties Hub program ready for you.


WHAT IS CASUALTIES HUB?
------------------------
Casualties Hub is a helper program for Casualties Unknown mods.

It can help you:
- See mods in your BepInEx Plugins folder.
- Open Nexus download pages for mods.
- Install supported mod ZIP files.
- Enable, disable, or remove local mods.
- Save custom skins, sounds, and other files as Protected Assets.
- Share enabled mod lists with friends.


HOW TO INSTALL CASUALTIES HUB
-----------------------------
1. Open "Casualties Hub Setup Wizard.exe".
2. Leave Pre-Release builds turned OFF unless you want to test unfinished versions.
3. Pick the newest version in the list.
4. Choose an install location. The default location is fine.
5. Press "Install / update Hub".
6. When Casualties Hub opens, set your Casualties Unknown folder in Settings if it was not found automatically.


HOW TO UPDATE
-------------
1. Open the Setup Wizard again.
2. Under "Detected Hub installations", click the Hub copy you use.
3. Pick the version you want.
4. Press "Install / update Hub".

The Wizard replaces Hub program files in that selected folder. It leaves your Protected Assets and normal Hub data alone.


HOW TO REMOVE OLD HUB COPIES
----------------------------
1. Open the Setup Wizard.
2. Press "Detect installations" if your copy is not already listed.
3. Tick each Hub copy you want to remove.
4. Press "Remove selected".

Only the exact Hub folders you tick are removed. The Wizard does not delete Casualties Unknown, BepInEx, mods, saves, or your game folder.


FULL REMOVAL - READ THIS FIRST
------------------------------
The "Also delete Hub data..." checkbox is optional and OFF by default.

Turn it on only if you want to completely remove Casualties Hub data from this PC. This removes Hub settings, logs, cached metadata, and Protected Assets such as saved skins or sounds.

If you may want those custom files later, leave that box OFF.


NEED HELP?
----------
If something goes wrong, open the Casualties Hub Discord from inside the Hub and include:
- Your Hub version
- What you clicked
- What you expected to happen
- What actually happened
