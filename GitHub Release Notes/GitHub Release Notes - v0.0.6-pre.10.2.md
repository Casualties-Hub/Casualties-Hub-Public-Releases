# Casualties Hub v0.0.6-pre.10.2

**GitHub tag:** `v0.0.6-pre.10.2`  
**Release title:** `Casualties Hub v0.0.6-pre.10.2`  
**Mark as a pre-release:** Yes

## What changed

- Added an **Enable Easter eggs** setting in Settings.
- Disabling Easter eggs immediately hides PapaZuck and disables its click actions.
- Removed the unnecessary per-page refresh button; **Master Refresh** and `Ctrl+R` remain available.
- Removed tooltips from the left navigation buttons.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Release checklist

1. Create the GitHub release using tag `v0.0.6-pre.10.2`.
2. Use title `Casualties Hub v0.0.6-pre.10.2` and mark it **Pre-release**.
3. Zip the contents of the normal release folder, not its parent folder.
4. Upload that ZIP under release Assets.
