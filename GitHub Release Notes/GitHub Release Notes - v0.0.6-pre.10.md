# Casualties Hub v0.0.6-pre.10

**GitHub tag:** `v0.0.6-pre.10`  
**Release title:** `Casualties Hub v0.0.6-pre.10`  
**Mark as a pre-release:** Yes

## What changed

- Removed the global text-tooltip rule throughout Casualties Hub.
- Long Dashboard descriptions no longer create giant white hover popups.
- Tooltips now remain only on buttons, where they provide useful action hints.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Release checklist

1. Create the GitHub release using tag `v0.0.6-pre.10`.
2. Use title `Casualties Hub v0.0.6-pre.10` and mark it **Pre-release**.
3. Zip the contents of the normal release folder, not its parent folder.
4. Upload that ZIP under release Assets.
