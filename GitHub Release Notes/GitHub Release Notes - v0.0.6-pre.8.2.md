# GitHub release guide - Casualties Hub v0.0.6-pre.8.2

## Release settings

- **Tag:** `v0.0.6-pre.8.2`
- **Release title:** `Casualties Hub v0.0.6-pre.8.2`
- **Target:** `main`
- **Pre-release:** checked

## Upload

Zip the complete unzipped release folder. Use this ZIP name:

`Casualties Hub v0.0.6-pre.8.2.zip`

Do not upload this guide with the release assets.

## Paste into GitHub

```md
# Casualties Hub v0.0.6-pre.8.2

## What changed

- Fixed the **Text size** selector so its selected text remains readable on the light control background.
- Fixed requested Share Code cards to use readable action buttons.
- Improved Share Code metadata matching. Older codes that contain a DLL name can now resolve to the correct mod and open its exact Nexus **Files** page.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Installation

1. Download and extract the release ZIP anywhere outside `Program Files`.
2. Run `Casualties Hub.exe`.
3. Select your Casualties Unknown folder in **Settings** if it is not found automatically.

This is a pre-release build. Install at your own risk and back up custom assets before testing.
```
