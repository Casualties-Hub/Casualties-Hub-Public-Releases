# Casualties Hub v0.0.6-pre.9

**GitHub tag:** `v0.0.6-pre.9`  
**Release title:** `Casualties Hub v0.0.6-pre.9`  
**Mark as a pre-release:** Yes

## What changed

- Restored the click-to-replace Dashboard card description view.
- Removed the giant white Dashboard hover popup caused by the global tooltip rule.
- Compacted Local Mods actions, search, and Share Code controls into matching control boxes.
- Replaced the long third-column control text with a compact `>` / `<` toggle.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Release checklist

1. Create the GitHub release using tag `v0.0.6-pre.9`.
2. Use title `Casualties Hub v0.0.6-pre.9` and mark it **Pre-release**.
3. Zip the contents of the normal release folder, not its parent folder.
4. Upload that ZIP under release Assets.
