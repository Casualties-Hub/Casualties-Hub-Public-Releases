# Casualties Hub v0.0.6-pre.10.1

**GitHub tag:** `v0.0.6-pre.10.1`  
**Release title:** `Casualties Hub v0.0.6-pre.10.1`  
**Mark as a pre-release:** Yes

## What changed

- Removed automatic tooltips that repeated button labels.
- Tooltips now appear only on buttons with a specific explanation of the action.
- Shortened tooltip display time to keep hints brief.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Release checklist

1. Create the GitHub release using tag `v0.0.6-pre.10.1`.
2. Use title `Casualties Hub v0.0.6-pre.10.1` and mark it **Pre-release**.
3. Zip the contents of the normal release folder, not its parent folder.
4. Upload that ZIP under release Assets.
