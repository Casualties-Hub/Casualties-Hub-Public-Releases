# Casualties Hub v0.0.6-pre.8.6

**GitHub tag:** `v0.0.6-pre.8.6`  
**Release title:** `Casualties Hub v0.0.6-pre.8.6`  
**Mark as a pre-release:** Yes

## What changed

- Compacted Settings colour controls: HEX remains visible, while RGB sliders are folded into expandable panels.
- Compacted Local Mods action controls and placed Share Code tools in a compact right-side box above the optional third column.
- Dashboard descriptions are now scrollable directly on their mod cards.
- Removed white Dashboard hover popups/tooltips from mod cards.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Release checklist

1. Create a GitHub release with tag `v0.0.6-pre.8.6`.
2. Title it `Casualties Hub v0.0.6-pre.8.6` and mark it **Pre-release**.
3. Zip the contents of the normal release folder, not its parent folder.
4. Upload that ZIP under release Assets.
