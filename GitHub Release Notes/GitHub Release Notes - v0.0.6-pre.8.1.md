# GitHub release guide — Casualties Hub v0.0.6-pre.8.1

## Release settings

- **Tag:** `v0.0.6-pre.8.1`
- **Release title:** `Casualties Hub v0.0.6-pre.8.1`
- **Target:** `main`
- **Pre-release:** checked

## Upload

Upload the complete **unzipped** release folder after you zip it yourself. Use this ZIP name:

`Casualties Hub v0.0.6-pre.8.1.zip`

Do not upload this guide with the release assets.

## Paste into GitHub

```md
# Casualties Hub v0.0.6-pre.8.1

## What changed

- Added four saved UI colour controls: page text, button text, button background, and accent.
- Added RGB sliders and pasteable `#RRGGBB` hex fields that apply immediately.
- Added a **Restore default colours** button.
- Fixed light navigation buttons using unreadable white labels by making their default text black.
- The selected tab and **Launch game** button now follow the chosen accent colour.

## Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.

## Installation

1. Download and extract the release ZIP anywhere outside `Program Files`.
2. Run `Casualties Hub.exe`.
3. Select your Casualties Unknown folder in **Settings** if it is not found automatically.

This is a pre-release build. Install at your own risk and back up custom assets before testing.
```
