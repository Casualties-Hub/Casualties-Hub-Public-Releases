# Casualties Hub v0.0.7

**GitHub tag:** `v0.0.7`
**Release title:** `Casualties Hub v0.0.7`
**Mark as a pre-release:** No

## What changed

- Official public v0.0.7 release.
- Moved the optional **Easter Eggs** control into **Settings → Accessibility**.
- Easter Eggs are disabled by default; enabling them is an explicit player choice.
- Updated the public README with current features, install guidance, privacy information, and relevant build history.

## User-facing release notes

### Highlights

- Official public `v0.0.7` release of Casualties Hub.
- Optional Easter Eggs are now managed through a compact Accessibility control and are off by default.
- Nexus browsing, Local Mods, Protected Assets, Modlist Share Codes, diagnostics, Hub Center, and optional online services are included.

### Online Services and privacy

Hub Online Services are optional and can be disabled in Hub Center. When enabled, the Hub uses a locally generated anonymous installation GUID for aggregate Community Activity counts, announcements, compatibility notices, and update information. Casualties Hub does not collect, store, or display an IP address for those metrics.

### Known issue

- Opera GX may not automatically open or come to the foreground when Casualties Hub opens a browser link.
