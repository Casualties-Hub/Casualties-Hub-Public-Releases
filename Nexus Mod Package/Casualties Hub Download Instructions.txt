==================================================
Where do I download Casualties Hub?
==================================================

Because Casualties Hub includes executable (.exe) files, Nexus Mods is unable to host the launcher directly.

To download it:

• Open the GitHub repository.
• Look on the RIGHT side of the page for "Releases."
• Click the release marked "Latest". Releases marked "Pre-release" are testing builds.
• Under "Assets", download casualties-hub-v<version>-win-x64.exe (Windows) or
  casualties-hub-v<version>-linux-x64.tar.gz (Linux).
• Windows: run the .exe. Linux: extract the archive and run casualties-hub.

GitHub:
https://github.com/Casualties-Hub/Casualties-Hub-Public-Releases

Thank you for downloading Casualties Hub!
